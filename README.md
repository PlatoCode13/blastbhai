# BlastBhai · ICB 2026

Tournament system for Indoor Cricket Blast 2026 (Hamburg, 26–27 Dec): live draw, schedule, team posters, live page, results with Man of the Match posters, and the rules presentation.

Live: https://platocode13.github.io/blastbhai/

- Everything runs in the browser; data is saved on each device until the shared backend (Cloudflare) is set up.
- Admin sign-in is a client-side curtain for testing only. Change it before match day.
